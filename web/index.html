Widgets

    Drag a widget by its title to move it, drag its corner to resize it, or use the buttons here. Double-click a corner to reset that widget's size.

    Where to change settings

    Every setting lives in a widget. Press → to show and jump to it, even if you hid or collapsed it.
      Settings take effect immediately and are remembered in this browser (localStorage); keys and firmware are kept in IndexedDB. Reset to default layout only restores widget placement, not settings. Changes to keys or firmware after a game has started apply after a page reload.

            🔊 Audio

            This engine build uses a null audio sink, so games run silently. Volume controls will be enabled once the core streams audio to the browser.

            📡 Local Play

            StatusNot available
            Switch local wireless (LDN) is not wired up in the browser core yet. When it is, consoles will link directly between browsers here, like Azahar Web's Local Play.

            Save States

            No save states.
            The Eden core does not expose save states to the browser yet. In-game saves live in the emulator's in-memory filesystem and are lost when the page reloads.
